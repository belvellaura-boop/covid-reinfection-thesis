# COVID-19 Reinfection Risk Analysis

Master's thesis project on COVID-19 reinfection using competing risks and multistate models.

## Methods

- Cumulative Incidence Functions (CIF)
- Cause-Specific Cox Models
- Multistate Modelling

## Repository structure

- ICU_State.Rmd: ICU discharged patients
- Hospital_State.Rmd: Hospitalized patients without ICU admission
- Home_State.Rmd: Home-managed patients
- General_Model.Rmd: Combined analysis of all states

## Software

- R
- mstate
- survival
- cmprsk
- tidyverse
- gtsummary
